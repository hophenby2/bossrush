# TH08 → TH31 子弹贴图映射表

目标：把 `th31.lua` 里占位的 `style_of()`（现在只有 ball_small / ball_mid /
ellipse 三种）换成「按原作 etama.anm 精灵逐型对上本项目最像的弹」。
本文是表；**第 1 版已经落进 `th31.lua`**（见文末「实现状态」）。PNG 素材仍未改。

颜色口径（**关键，别再改错**）：所有调用点给的都是**帧号**（`EX.color(c) = c + 1`、
各卡的 `th08_color(c) = c + 1`、`COLOR.*`），`color_of` 先 `−1` 还原成原作色号再查表。
不要反过来把调用点改成原色号。

各弹型的判定依据：`ecldata*.ecl` 的 SHOOT/SET_BULLET_TRANSFORM 反汇编（子弹类型逐张核过）：
卡 205 = ty 0（初始）/3/8；206 = 6 / 1；207 = 8；208 = 16 / 7；209 = 3；210 = 17（记录改成 2）；
211 = 19 / 7 / 10 / 5；212 = 3 / 2；213 = 10 / 2；214 = 11；215 = 14 / 15；216 = 20；217 = 6；
218 = 2 / 6；219 = 20 / 10；220 = 8 / 10；221 = 6 / 11。

尚未做（下一步）：

## 0. 原作贴图机制（都可本机复查）

| 事实 | 出处 |
| --- | --- |
| 敌弹/特效图集 = `etama.anm`（含 6 个子图集 etama..etama6） | `BulletManager.cpp:1596`（`PreloadAnm(ANM_FILE_SLOT_BULLET_AND_EFFECT, "etama.anm")`） |
| 21 种 bulletType → 5 个脚本号（弹/快生/普生/慢生/消散） | `BulletManager.cpp:299-310` `g_BulletSpriteScripts[21]` |
| **主弹精灵 = 该脚本首帧 baseSprite + color**（color 0..15 直接当偏移） | `BulletManager.cpp:189-193` |
| 出生/消散精灵另走偏移表（小图 `g_BulletSpriteOffsetSmall` / 中图 `…Medium`） | `BulletManager.cpp:196-220`、`:222-250`、`:272-290`；表在 `:32-37` |
| 碰撞盒/绘制桶按精灵高度分档（≤8 / ≤16 / ≤32 / 更大） | `BulletManager.cpp:1614-1700` |
| 精灵矩形（含坐标） | `etama.decl`（由 etama.anm 解出；脚本里 `ins_3(spriteN)` 即 base 精灵） |

要点：**主弹的 color 就是 sprite 偏移**，所以彩色变体在同一脚本的连续精灵里；
大弹（32×32 组）原作只用 color 0..7，所以 112/120/128 三组各 8 色、不重叠。
