# TH08 → TH31 子弹贴图映射表

目标：同时参考原作主弹精灵的**轮廓与可见尺寸**，选本项目默认大小最接近的现成样式。
**不增加子弹缩放，不改既有子弹判定。** `OriginalBulletVisual.style` 换图后恢复旧样式的
碰撞 A/B；所有显式写在符卡里的判定参数也保持原样。弹道、速度、发数和节奏不变。

本轮依据二进制 `etama.anm` 的 sprite 矩形、实际纹理及
`THlib/bullet/bulletStyle.lua` 的默认资源尺寸复核。PNG 素材不修改。

颜色口径（**关键，别再改错**）：所有调用点给的都是**帧号**（`EX.color(c) = c + 1`、
各卡的 `th08_color(c) = c + 1`、`COLOR.*`），`color_of` 先 `−1` 还原成原作色号再查表。
不要反过来把调用点改成原色号。

各弹型的判定依据：`ecldata*.ecl` 的 SHOOT/SET_BULLET_TRANSFORM 反汇编（子弹类型逐张核过）：
卡 205 = ty 0（初始）/3/8；206 = 6 / 1；207 = 8；208 = 16 / 7；209 = 3；210 = 17（记录改成 2）；
211 = 19 / 7 / 10 / 5；212 = 3 / 2；213 = 10 / 2；214 = 11；215 = 14 / 15；216 = 20；217 = 6；
218 = 2 / 6；219 = 20 / 10；220 = 8 / 10；221 = 6 / 11。

尚未做（下一步）：

1. **飞行途中 SET_SPRITE 的换贴图**只实现了卡 205 一处；卡 210（记录 2 → type 2）、
   卡 212（记录 1 → type 2/color 2）、卡 214（`BULLET_RECORDS` 里的 3/11 记录）目前只记一笔、
   不改观感（见各卡注释）。

3. **出屏回收半宽**：局部弹类的 `SPRITE_HALF` 等常量还是占位值（卡 215/216 按表应为 16，

4. t=12..15 的**自转**（原作 `ins_13`）与 t=19 的 4 帧动画仍未补。

## 0. 原作贴图机制（都可本机复查）

| 事实 | 出处 |
| --- | --- |
| 敌弹/特效图集 = `etama.anm`（含 6 个子图集 etama..etama6） | `BulletManager.cpp:1596`（`PreloadAnm(ANM_FILE_SLOT_BULLET_AND_EFFECT, "etama.anm")`） |
| 21 种 bulletType → 5 个脚本号（弹/快生/普生/慢生/消散） | `BulletManager.cpp:299-310` `g_BulletSpriteScripts[21]` |
| **主弹精灵 = 该脚本首帧 baseSprite + color**（color 0..15 直接当偏移） | `BulletManager.cpp:189-193` |
| 出生/消散精灵另走偏移表（小图 `g_BulletSpriteOffsetSmall` / 中图 `…Medium`） | `BulletManager.cpp:196-220`、`:222-250`、`:272-290`；表在 `:32-37` |
| 碰撞盒/绘制桶按精灵高度分档（≤8 / ≤16 / ≤32 / 更大） | `BulletManager.cpp:1614-1700` |
| 精灵矩形（含坐标） | 二进制 `etama.anm` 的 sprite 记录；主弹脚本选择 base 精灵 |

要点：**主弹的 color 就是 sprite 偏移**，所以彩色变体在同一脚本的连续精灵里；
大弹（32×32 组）原作只用 color 0..7，所以 112/120/128 三组各 8 色、不重叠。

### 激光

- 原作 `width` 是显示全宽；TH08 判定盒全宽是 `width/2`，命中半宽是 `width/4`。
- TH31 部分旧类把 `w` 直接存成判定全宽，另一些存显示全宽。本轮逐类标记口径，
  显示时恢复原作全宽，碰撞时统一换算；不再把 THlib 的 `w/7` 放大当成原作宽度。
- TH08 正的 startOffset 使用中间 70% 长度，已有预裁剪的实现不重复裁剪。
- 不可见的敌人接触判定条仍按矩形处理，不套用激光宽度口径。
- 展开/收束按原作保留中点的小判定段与 hitboxEndDelay，显示使用项目现有 `laser2`。

## 4. 保留的近似

- 只选现成样式，未导入原作主弹贴图、未增加弹体倍率。大五角星等没有完全同尺寸的候选，
  因此表中明确记录仍然存在的尺寸差异。
- 不补原作自转或循环动画；`water_drop`、`gun_bullet` 沿用项目现成样式的动画。
- 颜色口径沿用表 3，调用点仍传帧号，`color_of` 先减 1 后查表。
- 子弹旧判定 A/B 和显式的符卡判定保持不变；激光显示和命中范围按原作单独校准。
- 验证入口：`luajit tools/check_bullet_visuals.lua`。
