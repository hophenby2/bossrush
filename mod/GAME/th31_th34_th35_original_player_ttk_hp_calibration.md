# TH31 / TH33 / TH34 / TH35 原作 ECL 核对与血量表

> 本文以原作 ECL 为血量真值：进场 life、收尾阈值、继承关系和保护窗口都以反编译结果为准。
> 末尾记录 `th31.lua` / `th34.lua` / `th35.lua` 的运行时换算；TH33 是拍照卡，不按 HP 改。

## 结论

- 旧表的主要错误不是“差一点点”，而是把 **进场 life**、**收尾阈值**、**继承 life** 混在一起了。
- TH35 里最容易错的是没有 `lifeSet` 的连续符卡：它们继承上一非符的收尾阈值。`3637/3638/3639/3640 = 2,900/2,400/2,400/2,400`，不是 12,900 一类的进场值。
- TH35 的 `spellTimeout()` 不是无敌；`3619/3620/3621` 各 10,000 HP 都能打。真正全免的是 `setInvuln(...)`，例如 `3607` 的 1,080 帧。
- TH34 三姐妹不是三条独立血条。子机的 `999999` 是占位值；实际共享血条在父阶段 `Sub44..Sub51`。因此 `4441/4443/4445/4446/4447/4448` 不能按 999,999 算。
- TH33 是文花帖式拍照卡。`ins_141(N)` 表示拍照张数，不是 HP；把 N 填进 HP 会完全错。
- TH31 仍有近 30 项旧表错值，尤其 `150/154/158/162/166/170`、`174..190`、`458/459/466/468/469/474/476`。下面表里的值已由 ECL 重新核对。
- 运行时表已经按本文的 **ECL 有效 HP** 重新生成；换算只负责把原作最快 TTK 折算到移植版灵梦的 115.5 DPS，不再沿用旧表里的进场 life。

## 判读规则

| 现象 | 正确处理 |
|---|---|
| `lifeSet(N)` 后马上进阶段 | N 只是**进场 life**，不是最终 HP |
| `life_callback_ex` / `lifeThreshold` 给阈值 T | 有效 HP = 进场 life − T |
| 下一阶段没有 `lifeSet` | 继承上一阶段阈值作为本阶段进场 life |
| `setInterrupt(0, T, timer, sub)`（TH10） | 同时设收尾阈值 T 和时限；有效 HP = 进场 life − T |
| `spellTimeout()` | 只影响超时/计时表现，**不是无敌** |
| `setInvuln(n)` | 真正的全免窗口，n 帧 |
| 子机 `lifeSet(999999)` | 常见占位；去父阶段找共享血条 |
| `ins_141(N)`（TH095） | 拍照张数，不是 HP |

- `4466/4467` 是 `2,900 − 1,400 = 1,500`；`4468/4469/4471` 是 1,400。

## 移植运行时 HP 与本文的关系

- 本文表内的“有效 HP”是原作 ECL 值；运行时 `TH31_REIMU_HP` / `TH34_REIMU_HP` / `TH35_REIMU_HP` 存的是按移植版灵梦口径缩放后的值。
- 换算公式：`运行时 HP = round(ECL 有效 HP × 115.5 / 原作最快满火力 DPS)`。分母按作品和卡型固定：

| 作品 | 非符最快 DPS | 符卡最快 DPS | 非符系数 | 符卡系数 |
|---|---:|---:|---:|---:|
| TH31 | 2,088 | 288 | `115.5 / 2088` | `115.5 / 288` |
| TH34 | 3,224 | 432 | `115.5 / 3224` | `115.5 / 432` |
| TH35 | 1,368 | 270 | `115.5 / 1368` | `115.5 / 270` |

- 这保证移植版灵梦的**活跃伤害时间**等于原作最快机体的活跃伤害时间；`t1/t2` 仍单独还原原创保护窗口，不重复折算进 HP。
- TH34 三姐妹的 `Sub44` 有 19,000/18,000/17,000 三个 `$PLAYER_SHOT` 分支。移植版没有分支入口，统一取最快分支 `SHOT_MARISA_A = 2` 的 18,000；`Sub45..Sub51` 再按 ECL 的继承/收尾关系计算。
- TH35 `3607` 的有效 life 是 1，但 `setInvuln(1080)` 覆盖全卡，运行时继续按耐久卡处理，不写入可击破 HP 表。
- TH35 `3619/3620/3621` 的 10,000 是可击破 HP；运行时的 `t1/t2` 分别是原作 `setInvuln` 的 90/180/120 帧，`3621` 的血量分档阈值也按 10,000 → 运行时 HP 等比缩放。
- TH33 的 `CARD_HP=900/950/1000` 是移植运行时值；原作这里只有拍照张数，没有同口径 HP，因此本次不把 `ins_141(N)` 写进 HP 表。
