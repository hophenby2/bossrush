# TH31 / TH32 / TH33 / TH34 / TH35 原作 ECL 核对与血量表

> 本文以原作 ECL 为血量真值：进场 life、收尾阈值、继承关系和保护窗口都以反编译结果为准。
> 末尾记录 `th31.lua` / `th32.lua` / `th34.lua` / `th35.lua` 的运行时换算；TH33 是拍照卡，不按 HP 改。

## 结论

- 旧表的主要错误不是“差一点点”，而是把 **进场 life**、**收尾阈值**、**继承 life** 混在一起了。
- TH35 里最容易错的是没有 `lifeSet` 的连续符卡：它们继承上一非符的收尾阈值。`3637/3638/3639/3640 = 2,900/2,400/2,400/2,400`，不是 12,900 一类的进场值。
- TH35 的 `spellTimeout()` 不是无敌；`3619/3620/3621` 各 10,000 HP 都能打。真正全免的是 `setInvuln(...)`，例如 `3607` 的 1,080 帧。
- TH34 三姐妹不是三条独立血条。子机的 `999999` 是占位值；实际共享血条在父阶段 `Sub44..Sub51`。因此 `4441/4443/4445/4446/4447/4448` 不能按 999,999 算。
- TH33 是文花帖式拍照卡。`ins_141(N)` 表示拍照张数，不是 HP；把 N 填进 HP 会完全错。
- TH31 仍有近 30 项旧表错值，尤其 `150/154/158/162/166/170`、`174..190`、`458/459/466/468/469/474/476`。下面表里的值已由 ECL 重新核对。
- 运行时表已经按本文的 **ECL 有效 HP** 重新生成；换算只负责把原作各机体低速的活跃 TTK 中位数折算到移植版灵梦的 115.5 DPS，不再沿用旧表里的进场 life。

## 判读规则

| 现象 | 正确处理 |
|---|---|
| `lifeSet(N)` 后马上进阶段 | N 只是**进场 life**，不是最终 HP |
| `life_callback_ex` / `lifeThreshold` 给阈值 T | 有效 HP = 进场 life − T |
| 下一阶段没有 `lifeSet` | 继承上一阶段阈值作为本阶段进场 life |
| `setInterrupt(0, T, timer, sub)`（TH10） | 同时设收尾阈值 T 和时限；有效 HP = 进场 life − T |
| `spellTimeout()` | 只影响超时/计时表现，**不是无敌** |
| `setInvuln(n)` | 真正的全免窗口，n 帧 |
| 子机 `lifeSet(999999)` | 常见占位；去父阶段找共享血条 |
| `ins_141(N)`（TH095） | 拍照张数，不是 HP |

## 移植运行时 HP 与本文的关系（2026-11-02 更新）

- 用户指定只取**各可选机体的低速形态**。TH07 六个机体、TH10 六个机体；TH08 按 `Player.cpp::g_Player2ShtFile` 的四组队加八单人，共十二个样本。组队与单人的同一 SHT 各保留对应的可选机体权重。
- TH08 的附着使魔另取四个人类单机的低速样本；其余机体低速进入妖怪形态后无法击伤使魔，没有有限击破时间，因此不参与使魔 HP 的中位数。Boss 和普通敌机仍使用全部十二个低速样本。
- 换算公式：`HP = round(115.5 × median(ECL有效HP / 各低速机体DPS))`。取的是时间中位数，不是把 DPS 算术平均或取最大值。
- 数据和生成器：`original/low_speed_hp.lua`、`tools/th3x-tests/calibrate_low_speed_hp.py`。SHT 文件的 SHA256、每个样本的非符/符卡 DPS 和换算系数保存在 `tools/th3x-tests/low_speed_hp_calibration.json`。
- 采用持续全命中标定模型：满火力、固定命中相位，保留70点逐帧上限、整数符卡减伤、持续光束历史伤害及爆裂弹窗口。不模拟目标移动、漏弹、飞行时间差和永夜抄极端妖率加成。因此这些是**标定时间，不能当成移动战斗的实测 TTK**。旧最快 DPS 表缺少可复现采样记录，本次不继续沿用。
- 完全无敌和随后 `/9` 防御由原作帧数分别执行；不再用延长完全无敌或线性减伤代替。它们不计入 HP 换算。
- 使魔保留原始 HP，并单独记录换算系数。向父机传递伤害时先回到原始单位，取原作一半整数伤害，再换算父机单位，避免非符/符卡系数不同导致错误传伤。
- Boss 卡表取整；普通敌机和使魔保留换算后的浮点 HP（最低1），避免小血量目标经过多次取整。妖妖梦道中构造器直接传原作 life，旧的各面换算已移除；低速样本不适用仅限高速灵梦 A 的道中分面减伤。
- 999999 共享血条占位不作为可击破目标缩放；耐久卡、TH33 拍照张数保持原有定义。
- TH35 3619/3620/3621 仍可击破，3607 的 1080 帧全免仍覆盖整张卡。
