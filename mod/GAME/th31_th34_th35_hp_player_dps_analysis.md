# TH31 / TH34 / TH35：血量、自机火力与理论击破时间

> 只读分析文档。没有修改 `th31.lua`、`th34.lua`、`th35.lua` 或任何运行时代码。

## 结论先行

- 本项目四名自机的**贴身、全弹命中、无飞行损失**理想 DPS 上界为：灵梦 **115.5**、魔理沙 **160.8**（四束激光全中同一目标）、琪露诺 **155.6**、文 **400 / 3 = 133.33**（长期平均；实际是每 3 秒一次的 400 点爆发）。
- 灵梦、魔理沙、琪露诺的 DPS 都是把每个发弹源按“出弹数 ÷ 间隔 × 单发伤害 × 60”相加；文没有普通射击，拍照是 `take_damage2(400 - 距取景框中心距离)`，单目标最高 400。
- Boss 表里的 HP 是**移植版当前有效 HP**，不是原作的 `lifeSet` 原值；TH34 有明确换算，TH31/TH35 多数沿用原作值。原作减伤规则和移植版 `t1/t2` 必须分开看，不能拿原作 `life` 直接套移植版 DPS。
- 表内“超时”表示按该自机持续输出也赶在 `t3` 前打不死；“∞”表示耐久/不可伤阶段。文列对普通 Boss 是**忽略 `dmg_factor`** 的快门时间，原因是 `boss:take_damage2` 不乘 `dmg_factor`；但 `colli == false` 的耐久卡仍完全打不到。
- 小怪表的 TTK 从“进入可受伤状态”起算；`生成延迟` 只表示载体出现到子体可伤这一段，`0帧` 表示时间轴直接生成、出现即可伤，`初始免伤` 另算。每组总清场时间不能简单等于“单只时间 × 数量”，因为多只小怪会重叠、群攻和无缝刷怪。

## 四名自机的发弹源与伤害

### 灵梦：合计 115.5 DPS

| 发弹源 | 发弹节奏 / 子弹数 | 单发伤害 | 理想 DPS | 源码 |
|---|---:|---:|---:|---|
| 主弹（红方弹） | 每 4 帧 2 发 | 2 | 60.0 | `THlib/player/reimu/reimu.lua:43-49` |
| 针弹（四子机） | 每 2 帧 4 发 | 0.3 | 36.0 | `THlib/player/reimu/reimu.lua:50-54` |
| 满火力尾迹弹 | 每 8 帧 4 发 | 0.65 | 19.5 | `THlib/player/reimu/reimu.lua:55-61` |

尾迹只有 `lstg.var.man >= 80`（满火力）时才出现。三条合计 `60 + 36 + 19.5 = 115.5`。

### 魔理沙：主弹 60，四激光全中时合计 160.8 DPS

| 命中同一目标的激光束数 | 普通世界每束 0.34/帧 | 人界 `man >= 80` 每束 0.42/帧 |
|---:|---:|---:|
| 0 束，仅主弹 | 60.0 | 60.0 |
| 1 束 | 80.4 | 85.2 |
| 2 束 | 100.8 | 110.4 |
| 3 束 | 121.2 | 135.6 |
| 4 束 | 141.6 | 160.8 |

- 主弹：每 4 帧 2 发、每发 2 伤害，即 60 DPS（`THlib/player/marisa/marisa.lua:59-65`）。
- 激光不是实体飞行弹，而是四个子机位置每帧直接判定；普通世界只打最先命中的一个目标，每束 0.34（`:106-133`）；`man >= 80` 时穿透，每个被覆盖目标都吃 0.42（`:77-105`）。
- 表中的 160.8 是“四束都覆盖同一个大判 boss”的上界。小型小怪通常不会四束同时命中；用它算出的魔理沙小怪 TTK 偏乐观，应按 1–2 束，即 80.4–121.2 DPS 估计。

### 文：拍照 400 点/次，长期 133.33 DPS

- 拍照中心在取景框中心，命中范围内每个敌人调用 `take_damage2(400 - Dist(中心, 敌人))`，所以正中心最高 400，边缘更低（`THlib/player/aya/aya_system.lua:261-274`）。
- 蓄力：按住射击/低速时每帧 `+5`，需要 120 帧；普通状态每帧 `+2`，需要 300 帧。拍照后 CD 60 帧（`THlib/player/aya/aya.lua:28-63`、`:168-179`）。
- 理想循环：第一次快门约 2 秒，此后每 3 秒一次。`n` 发总时间约为 `2 + 3(n-1)` 秒；长期 DPS 极限 `400 / 3 = 133.33`。不保持低速蓄力时，间隔会变成约 6 秒。
- `boss:take_damage2` 不乘 `dmg_factor`，因此 Boss 的 `t1/t2` 全免/减伤窗口对文不生效；它仍受对象 `colli`、`protect` 和自身 `DMG_factor` 限制（`THlib/enemy/boss.lua:66-75`）。表中的文列按“从开打 2 秒后第一次有效快门、每 3 秒一次”计算。
- 文列显示的 `2.00 / 5.00 / 8.00…` 是快门实际落点，不是平滑 DPS：Boss 列从开打计 2 秒后拍第一张；小怪列会等到初始免伤结束后的下一张。

| 作品 | 原作单帧上限 | 符卡期间 | Boss 减伤计时器 > 0 | 非 Boss 减伤计时器 > 0 | 其他 |

| TH07（TH34） | 70 | 伤害 ÷7 | 同计时器下 ÷9 | 同计时器下归零 | TH07 还有仅限灵梦 A 的第四面 `×11/16`、第五/六面非 Boss `/2`，不是全局规则；`/Users/happyelements/th07/src/th07/EnemyManager.cpp:815-865` |
| TH10（TH35） | 无 70 上限 | 全局标记与 Boss 标记同时成立时再 ÷5，最低 1 | `damageReductionTimer > 0` 时跳过伤害 | 同 | 自机 `runtimeState` 为 0 或 2 时先 ÷5；`/Users/happyelements/th10/src/Enemy.cpp:861-889` |

移植版 Boss 统一走 `THlib/enemy/boss_system.lua:136-173`：

```text
timer < t1          → dmg_factor = 0
t1 … t2             → dmg_factor 线性上升
t2 … t3             → dmg_factor = 1
t1 == t3            → 耐久，dmg_factor 恒 0
timer >= t3         → 超时
```

本次三作的所有可击破卡实际都是 `t1 == t2`，所以普通自机 TTK 就是 `t1 + HP / DPS`。TH34 的符卡免伤值把原作“开卡动画 + ÷9 高防”折成等效全免；TH35 的 `t1` 是原作开卡保护的等效时长。表内列出的是移植版实际窗口，原作减伤口径单列。

## 使用这份表时要注意

- 所有 TTK 都是**单体、贴身、满火力、零走位、零命中损失**的理想值；实际战斗受弹幕逼迫、目标判定大小、无敌切换和转场影响。
- 魔理沙的小怪列按四束激光全中计算，真实小目标通常只能吃 1–2 束；灵梦/琪露诺的散射同理，目标越小越接近“主弹 + 少量侧弹”。
- 文的数值是离散爆发，不是连续 DPS：HP 不满 400 也要等一整次快门；小怪存活时间短于 2 秒时，文可能完全来不及拍第一张。
- 表中“原作 life”和“移植有效 HP”不可混用。TH34 的符卡、非符、小怪分别使用 0.6878、0.09825、0.09825/0.1429/0.1965 的换算；TH35 与 TH31 多数直接沿用原作有效 life。
- 无敌/高防时间以移植版源码的 `t1/t2` 为准。原作还有“符卡 ÷7”“Boss 减伤计时器 ÷9”“TH10 ÷5”等额外口径，已经在上面的总表说明；同一个显示 HP 下不能直接把原作玩家伤害搬到本项目的 TTK。
