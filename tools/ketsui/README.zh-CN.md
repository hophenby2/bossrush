# 绊地狱移植记录

## 依据原程序编写的 LuaSTG 对象

`mod/GAME/th43/native/` 使用 LuaSTG 原生对象运行从 ROM 翻译的回调。生成、炮口和弹体运动的参数从解密程序和图形 ROM 导出。顺序模式及整关练习的 TH43 入口均使用该运行层。

- `export_native.py` 从同一份解密程序导出五面共 1685 条生成记录、两条滚屏指令流、路径字节、速度向量、图块和已翻译对象用到的精灵。生成记录仍以主、副卷轴计数匹配。二、四、五面的卷轴要等遭遇战登记解锁才继续。五面还会写入新的计数对，原生成游标在重定位时继续消费后续记录。
- 已绑定回调的生成记录共有 1643 条，各面分别为 255、250、373、302、463。全表另有 42 条 `0xcfd7e` 记录，原程序立即释放对象槽。`0x0d0630` 的六种子机回调全部可分派，其中五面的 `0x1f` 按 `0xd2fd6` 推进路径，每八帧尝试发射，击破时由卷轴区段和路线决定反击弹。三面的 `0xd4f20` 和 `0xd552e` 履带炮车有独立炮塔瞄准和残骸耐久。二、五面的 `0xddafc` 大型飞机受击后切入 `0xdd9da` 坠毁状态。`0xd951e`、`0xd9942` 两种运输机共用飞行路径、炮塔追踪和三向发射回调，各自从原程序的按面配色表加载外观。
- `0xd87a0`、`0xd8c1a` 和 `0xd90ac` 的舱门飞机按各自的路径、六炮口和舱门动画推进。原程序一周目探针在第 3177 帧读到 `0x29` 型开盖字为 `0x1c`，首炮口偏移为 `0x03c0,0xffc0`。五面 `0x27` 型的 `0xd9024` 把单次开舱发射轮数设为三，机体血量设为 `0x1000`。`0xf3fa8` 的五面双管炮先结算装甲时钟，再根据炮组计数交替发射四发和两发。附着烟雾、击破得分和个别场景限制仍待接入。
- 一、三面的重型战车 `0xd7cdc` 有车体、舱门和两门炮四个原生对象。开舱推宽舱门判定，随后启用两门炮。`0xd7d52` 对两门炮取同帧最大扣血量，车体到阈值时由 `0xd84de`、`0xd8566` 拆炮。原程序探针在第 7385 帧读到一面车体血量 `0x980`、拆炮阈值 `0x500`，三面的对应值为 `0xa80`、`0x600`。两条二周目用 `0xf7064` 将中央发射角拆成相差八个角度单位的成对敌弹。

## 原程序的指令挂载

以下是 `ket` 2003/01/01 Master Ver. 的 **68000 程序地址**，用于核对关卡生成、敌机发弹和弹体运动的挂载关系。

| 层级 | 原版调度和状态 |
|---|---|
| 关卡生成 | `0x0cf69c` 从 `0x0cf64c` 选取生成表、路径索引表、路径基址。生成游标存在 `0x8126e4`。`0x0cf6ec` 用 `0x81247c` 和 `0x81247e` 的两个滚屏计数匹配 12 字节记录。同一计数对可消费多条记录。`0x0cb3f2` 和 `0x0cb528` 随两轴滚屏推进计数。记录含敌机类型、分配标志、12 位路径编号和打包的定点坐标偏移。 |
| 敌机绑定 | 关卡调度先写敌机组的路径指针 `+0x12`。`0x0cf94c` 从 `0x0cfd86` / `0x0f4730` 取一对类型例程，调用第一项的入口查询部件数并分配部件，将部件首地址和逐帧回调写入组的 `+0x06` 和 `+0x4c`，然后调用第一项入口加 8 的初始化例程。对象主循环在 `0x0cf884` 间接调用逐帧回调。 |
| 敌机路径与发弹 | 路径前四字节提供初始坐标。`0x0cfb5a` 处理开头的参数指令。`0x0cfc24` 消费方向、持续时间和参数指令。普通杂兵 `0x10` 的更新回调是 `0x0d08d2`，它用 `0x0ad240` 更新移动、用敌机组的 `+0x18` 计发弹间隔，并经 `0x0ae136` 检查出弹范围、经 `0x0adaf6` 读取自机位置并计算瞄准角，再从炮口偏移表 `0x0d0bfc` 取发射位置，调用 `0x0f6cc8`。 |
| 敌弹绑定与更新 | `0x0f6dca` 分配 0x40 字节槽位。弹型低 7 位选择 `0x0f8250` 的描述符。`0x0f6efa` 把描述符的 `+0x16` 写进弹槽 `+0x22`。弹池循环在 `0x0f75ec` 等位置间接调用。首发弹型 `0x09` 初始回调 `0x0f8cb8` 通过速度和角度查 `0x0d20` 处的向量表，写 `+0x1e` 后换成 `0x0f8d3a`。该回调把带符号速度加到 1/64 像素的打包坐标，并扣除低字的场景位移 `0x81252c`。 |
| 命中与失效 | `0x0b109c` 用敌弹中心对自机四边作包含边界的比较，再检查敌弹标志的 `0x51` 掩码。实测 A 型通常状态下四个半边为 `0xc0,0xc0,0x80,0x80`，即原屏幕两轴 3 和 2 像素。命中先置自机受击标志，再把敌弹换到 `0x0f6b04`。后者减半速度并绑定消失回调 `0x0f6b40`。敌机本体与自机则在 `0x0b0418` 起读取部件盒及接触标志。 |
| 首面关底 | 敌机类型 `0x70` 的初始化 `0x10caec` 给 Boss 注册独立事件表，逐帧回调 `0x10cefe` 先走 `0x0c174c` 分派事件，再走 `0x10f0e0` 结算血量和零件。攻击事件还会在 `0x0c1bec` 登记独立发弹槽，`0x111588` 表为该 Boss 的发弹槽提供各型初始化和更新入口。`0x10f7c8` 根据四外炮、两内炮以及主血量决定换段。`0x10f82a` 会清掉旧事件并登记事件 1，把部件击破状态交给新事件。`0x10fd38` 还处理两段各自的超时。 |

各面生成表为 `0x07c7c0`、`0x07df48`、`0x07f8f4`、`0x08187e`、`0x083e56`。对应有 262、261、378、309、475 条记录，包含控制事件。第一条记录 `0x07c7c0` 在主计数 112、子计数 0 调度类型 `0x10`，路径编号 `0x02c` 解到 `0x07d9ae`。它的路径指令 `89 01` 从纵坐标减去 `0x812528` 的滚屏偏移，`c0 16` 写速度索引，随后 `20 00` 指定方向和持续时间字段。

路径分派按字节区间解释。`00–3f` 给出移动方向，`40–7f` 在共用路径步进中给出零速度，两种记录都跟一个持续时间字节。持续时间非零时，内部计数相等才推进到下一条。`80–8b` 经表 `0x0cfcb0` 分派参数指令，其中 `80` 按两字节为单位向后跳，`81` 写部件参数，`82/83` 改部件的判定相关标志，`8a` 移除敌机。`c0–ff` 写下一个字节到速度索引。个别类型另有自己的状态和回调，例如首个 `0x10` 杂兵只用路径头初始化，之后在 `0x0d08d2` 里执行自己的移动和瞄准。

同一个敌机槽 `0x812a64` 两次都在探针的第 2579 帧执行 `0x0d0a04`。默认输入下，自机原始坐标为 `(0x0de4,0x0f80)`，发射角参数为 `0x25`。改按向右后，自机坐标为 `(0x0de4,0x2120)`，角参数变为 `0x22`。默认输入下首发弹在第 2651 帧命中，回调地址由 `0x0f8d3a` 换成 `0x0f6b04`。这里的帧号只供复核原程序。

首面关底用按键射击，在原程序主血量为 `0x1f209` 时由一门内炮和一门外炮的击破状态触发 `0x10f82a`，高于主血量换段线 `0x15f00`。同一帧登记事件 1，下一帧进入 `0x10e1ee` 初始化，随后执行 `0x10e212`。第二至五面已经从生成表解出关底逐帧入口 `0x112cd6`、`0x119a06`、`0x11fa18`、`0x125a4c`。

二面关底 `0x112962` 绑定移动表 `0x113b76`、事件表 `0x114538`、辅助表 `0x11553a` 和发射表 `0x116560`。`0x114e5a` 把中心盖板命中同时记入主血量与盖板耐久。`0x115236` 在盖板击破或主血量降到 `0xd000` 时换段。换段后的本体伤害由 `0x114d4e` 在两个重叠部件盒中取较大的扣血量。`0x1154d4` 独立处理两段超时。ShmupMAME 一周目探针维持自机保护计时并用按键射击，两段依次观测到事件 `0x1149a8`、`0x1149f2`、`0x114bd0`、`0x114b68`、`0x114a3a`，以及 `0x114aaa`、`0x114a84`、`0x114c2e`、`0x114bf8`、`0x114b98`。换段事件在第 26426 帧读到盖板击破标记 1 和主血量 `0x26ff0`。击破进入 `0x114666`，下一帧切到 `0x1146a0`。

三面关底类型 `0x76` 在卷轴计数 `0x110,0x6c` 调用 `0x1196b4`。移动、事件、辅助、发射表分别为 `0x11a73c`、`0x11ad44`、`0x11cc52`、`0x11ce0c`。`0x11bd1a` 至 `0x11bd4e` 对三块本体碰撞盒取同帧最大伤害，`0x11bd68` 在主血量低于或等于 `0x1ad00` 时调用 `0x11c56c`。`0x11c54a` 在两块部件均击破时调用 `0x11c61c`。一周目探针分别在第 42050、47911、50786 帧读到阶段 0、1、2，末次读到主血量 `0x0f6be`。最后阶段同帧登记 16 个发射槽 13。探针记录保存在运行目录的 `logic.tsv`。

三面中途的 `0xa0` 战舰在卷轴计数 `0x118,0` 调用 `0x132d7e`，逐帧入口为 `0x133262`。初始化挂载移动表 `0x134386`、发射表 `0x137cec`、绘制表 `0x133376`、辅助表 `0x1368ba` 和事件表 `0x13457a`。`0x135386` 分别结算炮位和舰体区块，`0x1364b8` 检查两块甲板是否都已击破，再启用三块核心判定。一周目探针在第 36859 帧进入初始化。

四面关底初始化 `0x11f800` 绑定移动表 `0x120086`、发射表 `0x121e18`、绘制表 `0x11fa38`、辅助表 `0x122e9a` 和事件表 `0x120612`。`0x120c74` 按当前阶段选 `+0x00`、`+0x2a` 或 `+0x54` 判定盒。前两段主血量阈值分别为 `0x51400` 和 `0x1a000`，转段例程分别为 `0x120f82` 和 `0x12100e`。五面初始化 `0x1254fe` 将里二周目标志复制到 `+0x502`，绑定移动表 `0x1267b8`、发射表 `0x12b89a`、绘制表 `0x125a6c`、辅助表 `0x128552` 和事件表 `0x126e50`。`KET_LOGIC_MODE=lateBosses` 的一周目探针在第 50551 和 82647 帧分别进入四、五面关底初始化。

五面初始组在 `0x125658` 分别设本体两个血量字段为 `0x75d00` 与 `0x83380`，里二周目初始主血量为 `0x61800`。受击例程 `0x12777c` 读取阶段 `+0x47a`，先对七个机身盒取同帧最大伤害。前三段更新敌机组 `+0x16`，阶段 3 至 5 更新 `+0x1a`。`0x127d2e` 与 `0x127dcc` 对后一个字段分别使用 `0x4ed00` 和 `0x2be00` 阈值。里二周目原程序探针在第 80683 帧读到五面关底进入，在第 110648 帧读到第二组血量置为 `-1`、登记最终退场事件 `0x1274a6`。

## 核对依据

- `ROM_START(ket)` 对应 2003/01/01 Master Ver.，程序 ROM SHA-1 为 `baa58d1ce47a707f84f65779ac0689894793e9d9`。PGM 的画面为 448×224、ROT270，时钟为 `10 MHz / (640 × 264)`。
- 68000 的 `0x10f24e`–`0x10f760` 分别扣除一面关底六个部件计数。`0x10f7c8` 检查外炮和内炮的击破状态，`0x10f80e` 比较主血量与 `0x15f00`。一面采样首次爆部件的帧是 9441。
- 二至五面从原版关卡标志和敌机控制器取得各段起止。关底类型分别为 `0x9081`、`0x7680`、`0x7980`、`0x6480`。四、五面关底初始主血量分别为 `0x7df00` 和 `0x75d00`。
- 用同一采样器运行 `ketl2omote` 和 `ketl2ura`，可观察表里二周目。两路均实测进入第五面。表路线在 121872 帧读到五面清场标志，里路线至 135000 帧仍在关底。上述数字来自每 12 帧采一次的控制器记录。
- Windows LuaSTG Sub 隔离测试用原生受击接口打掉一面内炮，依次触发五面的关底换段，并验证第五面击破后返回菜单和视口恢复。

## 已知差异

- 当前的转段与部件图层使用有限输入的采样。随自机变化的瞄准只覆盖已做横移对照的部分发弹。敌弹归属、零件爆炸的先后、击破后的分支与未击破时的循环仍有差异。
- 锁定、炸弹、残机补给和计分有近似。B 型、完整道具与倍率计分、原作音频和表里二周目尚未接入。旧第一面录像与当前关卡数据不兼容。
