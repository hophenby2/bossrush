# TH35四道中下潜相机崩溃

原错误：`th35_dive.lua:60: attempt to index global 'class' (a nil value)`。

`th35.lua`的`class`是局部变量；`dofile('mod/GAME/th35_dive.lua')`执行独立Lua代码块，不会继承调用者的局部变量。拆出的相机模块却仍通过`class.t10_motion_f32/ease`访问运动接口，首次生成`DiveEnemy00`时必然访问空全局变量。

修正为`loadfile(...)(class)`显式传入TH35上下文，模块在开头以局部变量接收并校验。相机曲线、缓动、单精度舍入、投影和ECL节奏保持原值。

真引擎验证还暴露出另一处独立入口错误：二至Extra道中登记的`TH10_1`既不在`mod/music.lua`中，也没有对应音频；如果道中恰好是roguelike首战，`PlayMusic`会先发生空索引。六个入口改用本项目已有且其他TH35入口正在使用的`TH10_2`。

验证命令：

```text
python tools/th36-tests/run_lua.py tools/check_th35_dive.lua
python tools/th36-tests/run_lua.py tools/check_fields.lua mod/GAME/th35_dive.lua
python tools/th36-tests/run_lua.py tools/check_roguelike.lua
python tools/th3x-tests/native_engine.py --output <新的独立目录> --games 35 --cases 3683 --frames 0 --speed 6000
python tools/th3x-tests/native_engine.py --output <另一个新的独立目录> --games 35 --cases 3671,3680,3681,3682,3683,3684,3685 --frames 0 --speed 6000
```

旧模块在无全局`class`的隔离LuaJIT中可复现原始60行报错。新增检查使用实际TH35装载路径，覆盖出生、9000帧相机推进、8944→8688回环、有限投影和上下文隔离。真引擎执行实际道中协程、对象、碰撞、渲染与退出清理。结果和APK哈希见`verification-th35-dive-2026-11-08.json`。
