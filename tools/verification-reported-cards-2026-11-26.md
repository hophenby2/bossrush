# 反馈卡片与移动端绘制修复

范围：雪莲华 38040「生魂信标『曼陀罗华』」、春雪篇 37020（三面关底一非）、永夜篇 39041（五面关底一非）。入口为正式挑战模式，固定种子输入 739、实际关内种子 58279；原生运行使用隔离存档。

雪莲华原作 `Bossmove.FixedUpdate` 将普通双 Boss 副体的 `life_last-life` 转入主体，副体的 89999 不是额外需要打掉的血量。修正导出器与两条四面路线前五阶段的总血量，保留 5500+5500 的独立双血槽和耐久阶段。「曼陀罗华」由 99499 修正为 9500。实际受伤路径中，基础伤害 88.748621934792，强化 15% 后为 102.06091522501，比例恰为 1.15；强化本身并未缺失。

性能改动：春雪移动端网格按原三角形顺序分块，以保守视锥包围盒跳过不可见部分；发射器步进不再逐帧分配闭包。雪莲华逐 tick 单精度舍入复用暂存格，曲线激光按原路径、宽度和 UV 合并提交，Windows 保留逐段路径并复用顶点表；背景粒子使用固定出生相机时刻，避免浮点相消使缓存反复失效。永夜静态弹图缓存解析结果，变弹种失效，动画弹和背景资源仍走原路径；激光使用独立中心的图像，避免每帧改写共享图片。移动端血圈使用固定几何批次，段数、淡化与颜色不变。

另外，自机弹层次改为 -660，常见 +50 偏移仍低于敌机 -600；横竖屏结算按钮统一为“保存录像”，沿用原有保留录像并进入保存界面的动作。

专项覆盖：三张卡各 1800 逻辑帧、每 120 帧比较采样状态与对象数量；雪莲华单卡完整时限模拟 2120 帧、清场残留为零；血圈顶点/UV/透明度对照、原生截图对照，以及春雪/永夜运动和绘制参数检查。汇总数据见同名 JSON。

限制：Mac 共用移动端逻辑与原生渲染接口，不代表 Android 真机帧率。跨进程 CPU 耗时有漂移，不用它宣称稳定帧率；裁剪与合批收益以实际提交量记录。状态摘要只覆盖部分弹体字段及对象数，不是所有激光路径的原作逐 tick 对照。曾比较原生表拷贝与 LuaJIT 循环，前者更慢，已撤回该替换。
