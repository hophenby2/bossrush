# TH31–TH36双语符卡名与TH36符卡背景

`export.py`按`card-audit-index.json`记录的原作ECL入口、卡号与实际难度提取名称，再匹配THBWiki符卡表的日文列与中文翻译列。默认中文，设置→其他→符卡名语言可以选择日本語。改动仅更新显示字段，历史槽位、卡号、HP及执行函数保持不变。

368个原作符卡注册：TH31 81、TH32 54、TH33 73、TH34 68、TH35 38、TH36 54。TH32的368号是仓库自制条目，不存在原作日文名称，保留作者标题。

`catalogue.json`记录入口、原作文件SHA-256、名称指令地址和THBWiki URL。HTML缓存的SHA-256也在其中。本地TH07只有汉化版，名字区已经改写，因此按原生符卡号从THBWiki的原作日文列恢复；其他五作从日文ECL二进制／独立ECL探针取名。TH095的5-8在ECL中写作「ロイヤルダイアモンドリング」，THBWiki表写作「ロイヤルダイヤモンドリング」：显式关联同一张5-8，日文显示仍保留ECL写法。

TH36原手填编号表把萃香、文的回忆组对应错了，并混入其他难度／其他原名。现在`tools/th36-tests/catalogue.py`以每个入口实际执行的日文名称匹配译名；例如原生65号为想起「百万鬼夜行」，不再标作天狗巨暴流。

TH36背景映射依据日文1.00a PE的`0x40c650`（开始符卡）、`0x40c0a0`（更新）、`0x40c4a0`（绘制）和`0x40cd60`（结束）。原exe SHA-256为`2978b17f6184d100d249d4311348dd30c5c32ec75c014b667a525b797d3d8813`。主背景VM如下，第三项为独立开场立绘脚本：

原作六面／Extra根据MSG序号>=24选择中Boss背景；移植省略MSG，按等价的原生符卡号分支。背景坐标从原作640×480屏幕原点换算为(-224,240)，两层按原顺序绘制。原版结束符卡清active位，立即停止背景绘制；没有自行追加淡出。立绘按原ANM的150／180帧演出自然退场。

检查：`luajit tools/spell-names/check.lua`使用正式`boss.card.add`验证全部名称切换、ID／HP／函数不变，以及TH36全部54张符卡的背景配对、透明度、坐标与清理；`tools/drop-tests/unit.lua`增加保护期、复活可操作阶段和死亡演出阶段的Bomb回归。`python tools/spell-names/native_probe.py --output <新的独立目录>`验证六作日文、设置控件和保存、保护期内消耗库存并生成正式Bomb效果。真引擎与APK结果另见`verification-2026-11-08.json`。
