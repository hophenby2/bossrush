# 十二作 Windows 性能巡检与优化（2026-11-21）

当前十二作均完成一个代表攻击和一个末关入口的原生采样，另对热点延长运行。所有测试进程在加载前锁定 BGM、SE 混音音量为零，采样行复查均为 0。玩家数据使用独立目录。

游戏逻辑版本基于 `54382570e6974d9a0337704c7af23c397829d742`。Windows 基于官方 Sub `0.21.129` / `8728b3f9e91e6cd577665a7f5777c6c7c23b5f31`；上游源码保持干净。已构建并更新根目录 `LuaSTGSub.exe`，最终 SHA-256 为 `f09734a801693599ffb83736f61de1e4d379b0ad166f173cdadc12f831428b1d`。

## 修复与对照

- 春雪/永夜：目标判定不再逐候选建立坐标向量。永夜把本帧目标成员整理为原生连续视图，保留原顺序；位置和碰撞开关实时读取，受弹几何由原 `NativeActorCollision.bind` 同步，无敌仍读取实时数据。自定义元表或数据失配继续完整查询。近边界候选保留原单精度公式，快速排除只使用包含舍入误差余量的保守范围。
- 春雪/永夜及雪莲华的目标代理缓存另修复弱键值反向引用环：按固定工作量清理引擎已释放对象，保留所有存活代理的身份和状态，绑定新自机时清空旧缓存。
- 雪莲华：父子变换省去中间向量，保留每一步单精度舍入与独立返回值；`Damage1` 合并同一比较中重复的纯坐标读取，保留敌机/Boss 顺序、严格边界、伤害、击中效果及销毁行为。原生成脚本没有修改。
- Like Dreamer：敌机成员增删或练习恢复时才重建排序视图；代理字段仍实时读写。弹链原地稳定压缩，保留终帧节点、活动序号和下一帧摘链时机。特效及得分绘制使用现有数字颜色接口，减少临时 Color 分配。
- 栖霞园：修复测试中阻断六面的曲线激光报错。样式编号与纹理分开映射，恢复颜色索引、16 行 UV、包络、节点及消失绘制；尺寸在注册时读取，避免逐帧查尺寸。依据用户提供的 THEIS 仓库 `10b2fb77c509413e2975d923ce7c92f259fe11d6` 中 `code/data/THlib/laser/bentlaser.lua`。
- 原作五作、夏夜祭及祈华梦在所列入口未复现持续的高占用瓶颈，保留其攻击及背景实现。夏夜祭另运行实际攻击至结算，并做 7200 tick 生命周期检查：发射器稳定约 66，后段存活对象约 950，未出现持续累积。

## 逻辑和画面检查

- 原生查询三条路径共 72,000 组比较，包括边界、自定义属性、遮蔽字段、无敌、NaN/Inf 和视图 GC。
- 多层 Unity 变换 20,000 组逐位比较；Damage1 与原始生成代码 5,000 组行为对照；春雪/永夜目标碰撞 20,000 组比较。
- Like Dreamer 18 组完整 Boss 生命周期的前后输出相同，61 个练习入口检查通过；另检查敌机视图和弹链顺序/回收。
- 雪莲华及 Like Dreamer 第 120、600 帧的完整战斗视口逐像素相同；雪莲华全图差异只出现在引擎 FPS 区域。数字颜色、对象绘制各 96 种组合的前后全图相同。
- 栖霞园 16 行 UV、颜色、包络、节点和消失绘制检查通过，六面原生运行 3600 帧并检查实际曲线画面。
- 窗口化和禁用追帧专项已运行；最终二进制还单独复查两项，结果见 `allworks-release-check`。

## 范围和仍需注意的结果

永夜的密集段仍有部分超过 16.67 毫秒的慢帧；本次优化有明显收益，但不能宣称所有场景都稳定 60 FPS。十二作入口覆盖不等于全部 1451 个练习项、全部机体、全部道中或随机双 Boss 组合。Mac、Android 未在本次构建或实测。

Like Dreamer 有一次诊断进程在 `XAudio2_9Redist.dll` 发生访问异常，后续相同场景多次没有复现；该次失败不计作通过。最初三个顺序入口的 JSON null 参数问题已修正并重跑。
