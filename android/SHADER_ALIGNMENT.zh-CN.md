# Mac／安卓 shader 对齐口径

基准为项目 `shader/` 中的全部八份 HLSL，以及 Windows LuaSTG-Sub `v0.21.129` 的颜色、雾效、采样器和后处理混合实现。Mac Metal 和 Android GLES 使用同一份源公式；差别只在 GLSL 版本与绑定声明。

## 八份后处理

| HLSL／GLSL 同名文件 | 对齐内容 |
| --- | --- |
| `alpha` | 视口裁剪、alpha×3.333、原文件的255上限 |
| `gray` | 灰度权重、混合顺序、保留alpha的条件 |
| `color_set` | HSL公式、饱和度为0、色相只加／减一次、开关边界 |
| `screen_save` | RGB原样复制，输出alpha为1 |
| `gaussian_blur` | 原文件实际为摄影区域遮罩；框外RGB除4，alpha为1 |
| `texture_BoxBlur49` | 49点等权、原偏移表、原累加顺序、视口内缩1像素、半径按屏高／480换算 |
| `world_rotate` | 补齐移植；保留原参数顺序、负缩放、近零缩放分支和裁剪 |
| `thl_distortion` | 补齐移植；原HLSL中的构造分隔符和未定义uv做语法修正，逗号表达式显式取右值dist |

后两项没有添加新的游戏调用。打包时比较 HLSL 和 GLSL 文件清单，后续遗漏移植会直接报错。

## 共用渲染

- 雾在片元阶段按世界坐标到相机的实际距离计算，保留线性、指数、平方指数三种公式；不使用投影后的z／w或顶点雾浓度插值。
- 雾目标色的alpha为 `fog_color.a × source.a`，与RGB一起混合。透视相机和所有混合模式同步相机及雾参数。
- 普通几何仍用直通色配SRC_ALPHA；这与Sub几何shader预乘RGB后配ONE对应，不能重复预乘。
- 后处理直接使用HLSL输出RGB，另建源系数ONE的混合模式；覆盖模式同时覆盖目标alpha。
- 相机或同类雾参数变化前提交旧批次，下一批取得新的uniform快照。
- GLSL浮点计算和UV插值使用highp，移除移植版主动降低的精度。

## 采样及参数

八份后处理共用 `shaders/sampling.glsl`，在打包时注入正文。对应Sub的0..7采样器：点／线性、循环／钳制／边界；线性采样分别处理四个相邻texel及边界权重，不修改源纹理的全局采样器。

`v0.21.129` 的 `PointBorderWhite`／`LinearBorderWhite` 实际仍沿用黑边（Windows源码保留了 `TODO: white?`）；移植保留该版本的实际行为。常见调用参数6为LinearBorderBlack。

每次后处理清零再提交八个float4常量槽，避免少传参数时遗留上一帧的数据。现有八份shader只读取主纹理；兼容入口也保留额外纹理的绑定参数。
