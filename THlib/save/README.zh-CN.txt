Boss Rush HD 0.3.0 — 多存档与 PC / Android 双向同步

入口
在标题菜单选择“存档 / 同步”，或在游戏中点右上角同名按钮、按 F10。
PC 使用本机浏览器；Android 在游戏内打开管理页面。页面运行于本机，不依赖云服务。
使用完点击“返回游戏”。战斗期间打开管理页会暂停；切换存档会保存旧槽并返回标题。
继续游戏从该槽最近的关卡检查点开始，不支持保存任意一帧的战斗快照。

多个存档
首次启动自动将旧 User/Score.dat、Spellcard.dat、saving1.file 复制到“原有存档”。
旧文件保留，不删除、不覆盖。今后各槽位写入 User/profiles/<本地编号>/。
User/profiles/index.json 记录当前槽与列表；写入时保留 .bak，索引提交失败不切换内存状态。
可以新建、复制、重命名、切换、归档与恢复。最多同时显示 128 份存档。
每份存档隔离成长、金币、解锁、成就、符卡历史与“继续游戏”数据。
按键、画面、音量等设备设置不随存档切换；录像库仍属于本机。

离线导入 / 导出
1. 在“我的存档”勾选一份或几份，进入“口令 / 二维码”。
2. 按需要选择是否附带“继续游戏”数据，生成 BRS1 开头的口令。
3. 可复制口令、保存 .brsave 文件，或显示二维码。对方可粘贴、读文件、相机扫码或读二维码图片。
4. 读取后只产生预览。勾选其中一份或几份，再选择导入方式、确认。
5. 默认“保留为新存档”。相同来源、相同内容跳过；不同内容保留同步副本。
   选择替换时自动将旧槽归入备份。当前正在使用的槽须先切换，才能被替换。
   未附带检查点的交换包在替换时保留该槽已有检查点。

大二维码会分片，可手动翻页或每 1.5 秒轮播。接收端可乱序、重复扫描，收齐后才校验。
每组最多 256 张二维码；超过时应取消附带检查点，或使用口令、文件、局域网。
交换包解压后最多 16 MiB，口令/文件最多 24 MiB。过大的检查点可留在本机，只同步成长记录。

同一网络 / 热点传输
两台设备均打开“存档 / 同步”，连接同一 Wi-Fi，或一台开启热点、另一台连接它。
在“局域网同步”选择共同网络的本机 IPv4 地址，将 BRP1 配对码或二维码交给另一台设备。
另一台输入或扫码连接后，可以选择对方的若干存档拉取，也可以发送本机选中的存档。
收到的数据仍需在接收区勾选确认。配对码有效 10 分钟，更新码会使旧码失效；关闭管理页停止配对。
Windows 防火墙如询问，请允许游戏在当前局域网接收连接；路由器的访客隔离可能阻止互联。
传输使用局域网 HTTP 和临时随机密钥，不是互联网云同步，也不提供跨公网穿透或 TLS 加密。
当前支持 IPv4 的私有网络、热点与本机地址。

实现与恢复
codec.lua：BRS1 数据格式、SHA-256、Base64URL、带输出大小限制的 LZ 编码。
profiles.lua：数据校验、旧数据迁移、独立槽、导入事务、冲突副本与备份。
transport.lua：Windows Winsock / Android 与 macOS POSIX 的非阻塞 HTTP，每帧有收发预算。
service.lua：限时配对、双向传输、选择性导入、本机管理页面与游戏状态衔接。
web/：完全离线的界面、二维码编码和解码，依赖版本、来源与许可证见 web/vendor/。
安卓通过本机 WebView 调用相机、剪贴板与系统文件选择器，用户操作时才请求相机权限。
存档口令仅按 JSON 数据解析，不执行传入口令中的 Lua；未知文件名、坏校验与越界数据会被拒绝。
替换与归档前的数据可在管理页备份区恢复，原始目录也仍保留。

PC 更新包
将 BossRushHD-PC-save-sync-0.3.0.zip 解压到现有 PC 游戏目录，覆盖同名脚本，再正常启动。
它不包含玩家 User/、replay/ 或新的 Windows 引擎；依赖现有 LuaSTG Sub / LuaJIT 运行时。
Android 则安装 0.3.0 APK。两端均更新后，才能使用多存档和新的同步协议。

验证
tools/save-tests/ 中的测试仅在临时目录内创建模拟玩家数据，不读写桌面真实 User/。
单元检查覆盖二进制编解码、迁移、选择性导入、冲突、备份、损坏输入与索引提交失败。
integration.py 覆盖两个独立游戏实例的配对、拉取、推送、接收确认与配对失效。
browser.cjs 覆盖真实浏览器界面、QR 编码/图像解码、分片重组与窄屏布局。
在 macOS / Linux 且已准备引擎缓存后，python3 tools/save-tests/run.py 可构建宿主 cjson 并运行回归。
附加 --browser 运行 Puppeteer 回归；可用 BOSSRUSH_PUPPETEER 指定模块绝对路径。
Windows x64（Wine）与 Android 模拟器互传、1280×720 相机视频、Android QR 图像解码均已验证。
物理 Windows 机器和两台真机在 Wi-Fi / 热点下的相机与网络组合仍需进一步回归。
